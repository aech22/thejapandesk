# How to Set Up a Japanese Keyboard on Any Device

Most learners should set up romaji input, not kana input. Romaji input lets you type Japanese using the same QWERTY keyboard you already know, converting letters like "ka" into か as you type. Kana input requires memorizing a separate key layout where each key produces a specific kana character directly. Unless you already touch-type in Japanese for work, romaji input will get you writing usable Japanese within minutes, and it reinforces the romanization patterns you are probably already learning from textbooks.

The setup itself is a built-in operating system feature. You do not need to buy software or a special keyboard. Every major platform — Windows, macOS, iOS, and Android — ships with a Japanese input method editor (IME) that you switch on through system settings.

## Setting up a Japanese keyboard on Windows

Open Settings, then go to Time & Language, then Language & Region. Under "Preferred languages," select Add a language and search for Japanese. Install it, and Windows will add the Microsoft IME automatically.

Once installed, you will see a language indicator near the clock, usually showing "ENG" or "JP." Click it, or press the Windows key plus the space bar, to toggle between your existing keyboard and Japanese input. With Japanese input active, a small "A" or "あ" icon appears in the taskbar, letting you switch between alphabet mode and hiragana mode without changing the language setting itself.

To type in Japanese, make sure the IME is set to hiragana input (あ), then type romaji as usual. Typing "nihongo" produces にほんご, and pressing the space bar brings up a list of kanji conversions if you want 日本語 instead. Press Enter to confirm your choice.

## Setting up a Japanese keyboard on Mac

Go to System Settings, then Keyboard, then Input Sources, and click the plus button. Search for Japanese and add it. macOS offers a few input methods under this heading; choose "Japanese" (which defaults to romaji-based input) rather than "Japanese - Kana" unless you specifically want kana input.

Switch between languages using the input menu in the menu bar at the top right of the screen, or by pressing Control plus space bar, depending on your keyboard shortcut settings. As with Windows, typing romaji while the Japanese input source is active converts it to hiragana, and the space bar cycles through kanji options.

## Setting up a Japanese keyboard on iPhone and iPad

Open Settings, then General, then Keyboard, then Keyboards, then Add New Keyboard. Select Japanese. iOS will ask whether you want Romaji or Kana layout — choose Romaji unless you have a specific reason not to. You can also enable the Japanese-Kana 10-key layout, which mimics the flick input style used on Japanese feature phones and is common among Japanese users, but it has its own learning curve separate from either romaji or kana typing.

To switch keyboards while typing, tap and hold the globe icon at the bottom of the keyboard, or tap it repeatedly to cycle through your installed languages.

## Setting up a Japanese keyboard on Android

Android's setup varies slightly by manufacturer, but the general path is Settings, then System, then Languages & Input, then Virtual Keyboard, then Manage Keyboards. If Gboard is already installed, open it, go to Languages, and add Japanese. Choose the romaji layout when prompted.

Switch between keyboards using the globe or language icon on the keyboard itself, which appears once more than one language is active.

## Romaji input versus kana input

Romaji input converts Latin letters into kana as you type, following the same romanization most textbooks use: typing "shi" gives し, "tsu" gives つ, and so on. Because you are reusing an existing keyboard layout, there is no new key positions to memorize. This is why nearly every Japanese-language course and app assumes you will type this way.

Kana input assigns one physical key to one kana character, so there is no conversion step from romaji to kana — you press a key and the corresponding hiragana appears directly. This can be faster for proficient typists because each keystroke produces a full syllable rather than two or three letters. But it means learning an entirely new key layout, separate from both the English alphabet and from romaji spelling patterns. Native Japanese typists sometimes use kana input, but a large share also use romaji input, because it requires no retraining if they already know a standard keyboard.

For a learner, kana input offers little advantage and a real cost: you would be memorizing a key layout instead of focusing on actual vocabulary and grammar. Romaji input, by contrast, doubles as practice, since typing "gakkou" to produce 学校 reinforces the same romanization you use when looking up words in a dictionary or writing furigana notes.

## Typing kanji, punctuation, and switching back to English

Once hiragana appears on screen, pressing the space bar (or the conversion key labeled 変換 on some on-screen keyboards) brings up a list of kanji and word candidates that match the sound you typed. Arrow keys or additional space bar presses move through the list, and Enter selects the highlighted option. If no conversion is needed, pressing Enter directly confirms the hiragana as typed.

Japanese punctuation — the 。marks and 「 」 quotation brackets — usually has its own romaji shortcuts built into the IME, such as typing a period to get 。and a comma to get 、. These shortcuts are consistent across Windows, Mac, and mobile IMEs, so once you learn them on one device they carry over to the others.

Switching back to English input uses the same toggle you used to turn Japanese on: the language switcher near the system clock on desktop, or the globe icon on mobile. Many learners keep both input methods active throughout a study session, flipping back and forth between an English dictionary app and a Japanese typing app or chat.

## What to check before you start typing

Confirm which romanization style your textbook or app teaches, since a small number of sound combinations have more than one accepted romaji spelling (for example, both "shi" and "si" can produce し in most IMEs, and both usually work without extra setup). If a particular key combination does not produce the sound you expect, check your IME's settings menu, where most input methods let you review or adjust romaji mapping rules. For most learners starting out, the default settings on any of the four platforms above will work correctly without any adjustment at all.
